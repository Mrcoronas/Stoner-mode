
# Stoner Mode – Web Game

This is a simple browser-based game called **Stoner Mode** featuring collectibles.

## How to play
Simply open [the game link](https://your-username.github.io/stoner-mode-game/) after publishing with GitHub Pages.

## How to publish

1. Fork or clone this repository  
2. Enable GitHub Pages:
   - Go to **Settings > Pages**
   - Select **Branch: main** and **/ (root)**  
3. Access the game at:  
   `https://your-username.github.io/stoner-mode-game/`

Enjoy the game!
